# OBDLSS5 Oblivion v0.1.0

Experimental public installation kit for classic 32-bit Oblivion.

## Included

- Transactional PowerShell install, verify and uninstall scripts.
- Windowed SDR baseline configuration for the flat D3D11 route.
- Dependency provenance and SHA-256 records.
- Controlled static OFF/ON screenshots and validation notes.

## Important limits

- This package does not redistribute third-party binaries.
- NVIDIA officially documents DLSS 5 3D-Guided Neural Rendering for GeForce
  RTX 50 Series hardware.
- The author's RTX 4090 result uses an experimental SF-v2 NR runtime and is
  not official NVIDIA support.
- The complete OBDLSS5 A01-A12 specification gate remains partial.
